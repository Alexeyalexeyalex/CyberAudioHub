# ------------------------------------------------------------
#  Важно про видеокарту и озвучку
# ------------------------------------------------------------
# coqui-tts тянет за собой torch, а pip по умолчанию ставит его сборку
# без CUDA — озвучка тогда пойдёт на процессоре и будет медленнее раз в
# двадцать. Ставьте torch ДО остальных пакетов, с индекса NVIDIA:
#
#   pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu128
#   pip install -r requirements.txt
#
# torchaudio обязателен: XTTS импортирует его у себя внутри. Ставить его
# отдельной командой с PyPI нельзя — оттуда приедет сборка без CUDA и
# потянет за собой второй, процессорный torch.
#
# Именно cu128, а не cu121. Причин две, и каждой хватает по отдельности:
#
#   1) Карты 50-й серии (RTX 5070/5080/5090, архитектура Blackwell, sm_120)
#      появились после CUDA 12.1. В сборках cu121 для них просто нет
#      скомпилированных ядер — то же самое, из-за чего int8 не работает
#      в CTranslate2.
#
#   2) Индекс cu121 давно заморожен: последний torch там — 2.5 под Python
#      до 3.12 включительно. На более свежем Python pip честно отвечает
#      «No matching distribution found for torch», и это не сбой сети.
#
# Для карт 40-й серии и старше подойдёт и cu126, но cu128 работает и там.
#
# Проверить, что всё сложилось:
#   python -c "import torch; print(torch.cuda.is_available(), torch.version.cuda)"
#
# На распознавание речи это не влияет: faster-whisper работает через
# CTranslate2, и torch ему не нужен вовсе. Но torch притащит свои версии
# nvidia-cublas-cu12 и nvidia-cudnn-cu12 — после установки стоит один раз
# запустить main.py и убедиться, что распознавание тоже поднялось.
