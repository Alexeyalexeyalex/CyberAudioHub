## Ещё не подтверждено на экране телефона

Телефон заблокирован. Установка отдельного Android-тестового пакета отклонена устройством (`Install canceled by user`); повторная установка без разрешения не выполнялась. Само приложение 1.6 установлено успешно.

Остаются экранная проверка нового входа/профиля, оформления диалогов, полноэкранного читателя, переключателя слежения и центральной пластинки. Соответствующий код собран; это не равно пройденной проверке на устройстве.

Для последующей проверки оставлена изолированная конфигурация приложения `http://127.0.0.1:2078` через `adb reverse`. Книга «мир для лекаря» скачана во время QA; её две текстовые главы — синтетические тестовые фразы, не настоящая расшифровка книги. Тестовый аккаунт и тестовые материалы не относятся к рабочему серверу. После завершения проверки нужно убрать тестовые материалы через приложение и выбрать требуемый адрес сервера в настройках.

Команды автоматических проверок из корня: `node --test tests/*.test.cjs`, `python -m unittest discover -s tests -v`, `python application/build_apk.py --offline`. Отдельная Android-проверка описана в `application/README.md`.

- 45 JVM-тестов прошли, включая HTTP-воспроизведение конфликта обновления cookie, запрет ответа старого каталога после выхода, политику восстановления и сохранение списка книг при выходе.
