# CyberAudio Hub для Android

Актуальное приложение — нативный Java-проект в `android/`. Старые файлы Kivy и Buildozer сохранены только как архив; в APK они не входят.

## Сборка на Windows

Нужны JDK 17/21, Gradle 8.9+ (8.x), Android SDK с платформой 35 и Build Tools 36.0.0. SDK задаётся через `android/local.properties` (`sdk.dir=...`) или `ANDROID_HOME`.

```powershell
python application/build_apk.py
```

Скрипт находит Gradle в PATH или пользовательском кэше, собирает APK, запускает тесты и Android Lint. Только после успешных проверок обновляет `application/CyberAudioHub.apk` и `application/version.txt`. Интернет нужен для недостающих зависимостей. Параметры: `--gradle`, `--java-home`, `--offline`, `--no-publish`.

Версия задаётся единожды в `android/app/build.gradle`. Для обновления поверх старого приложения сохраняйте signing key / debug keystore: удаление приложения стирает скачанные книги.

## Интерфейс

- Иконка Android повторяет знак сайта: наушники с открытой книгой, бирюзово-сиреневый градиент и тёмный фон. Адаптивная форма сохраняет рисунок при круглом и скруглённом оформлении; для тематических иконок Android 13+ предусмотрен отдельный монохромный слой.
- На первом входе только логин и пароль; адрес по умолчанию — `http://188.32.242.100:2077/`. Шестерёнка настроек доступна без входа. Ранее выбранный пользователем сервер сохраняется; смена сервера требует нового входа, повторное сохранение того же адреса — нет.
- В настройках всегда доступна кнопка «Войти / сменить аккаунт», даже при сохранённой, но недействительной сессии. Она принудительно открывает форму входа, не проверяя сеть и не удаляя текущую сессию или скачанные книги. С версии 1.7.3 прежняя сессия заменяется только после успешного ответа с новой cookie и профилем; неудачная или прерванная попытка входа её не удаляет.
- После успешного входа или регистрации медиатека становится корнем истории экранов: системная кнопка «Назад» не возвращает старую гостевую полку или форму входа. Навигация назад внутри книг и папок сохраняется.
- Настройки показывают сохранённый профиль без сетевого запроса. «Выйти из аккаунта» с подтверждением удаляет сессию и профиль, но сохраняет скачанные книги и адрес сервера. Данные профиля находятся в постоянных файлах настроек, а не в кэше обложек.
- Нижняя навигация: медиатека, личные папки, центральная пластинка плеера, скачанное, профиль. Пластинка возвращает к текущей или последней включённой книге.
- Поиск, сортировки, обложки, рекомендация книги и иерархия каталога.
- Плеер с отдельными кнопками глав и ±5 секунд, фоновым воспроизведением и уведомлением.
- Текст главы или всей книги, подсветка прочитанного, отключаемое слежение, полноэкранное чтение. Читатель доступен только у скачанных книг и читает исключительно локальные файлы; скачанное аудио также воспроизводится с телефона.
- Полноэкранный читатель оставляет управление сверху. Отображаются только видимые абзацы, поиск текущего слова — двоичный; большой текст не пересоздаётся каждые 200 мс.
- Загрузка аудио и доступного текста для офлайн-прослушивания; прогресс загрузки сохраняется при переходе между экранами.
- Профиль, достижения, статистика, поиск друзей, заявки и сравнение достижений работают с API сайта.
- Расширенные веб-функции, включая админку и изменение обложек личных папок, открываются внутри приложения в текущей сессии.
- Настройки адреса сервера и экономии трафика. Без доступного сервера медиатека показывает скачанное.
- С 1.7.4 временный сетевой сбой не оставляет медиатеку навсегда в офлайне: есть кнопка подключения и повторные попытки, пока экран открыт, с интервалами от 1,5 до 30 секунд. Явно выбранный раздел «Скачано» остаётся локальным. Ошибки 401/403 показывают просьбу войти/сообщение об ограничении доступа и не запускают бесконечный опрос.

## Данные и совместимость

Контейнер `.cah` (CAH1), ключ, каталог книг и имена SharedPreferences сохранены. Это собственный формат приложения, а не полноценная DRM-защита. Установка APK поверх прежней версии не требует повторного скачивания.

В версии 1.7 сессия и публичные данные профиля сохраняются на телефоне. Пароль не сохраняется. При сетевой ошибке виден сохранённый профиль с соответствующей пометкой; он не даёт прав администратора и не заменяет проверку входа сервером. Запоздалые ответы прежнего сервера или прежнего входа не перезаписывают текущую сессию. Если сервер отклонил сессию, потребуется повторная авторизация.

Сессия хранится в `shared_prefs/cyberaudio.xml`, отдельно от каталогов `cache`/`code_cache`. Обычная очистка кэша не должна её удалять; удаление всех данных приложения или переустановка с удалением APK удаляет и вход, и скачанные книги. В 1.7.3 закрыта найденная по коду ошибка: перед повторным входом прежняя сессия больше не стирается заранее. Это защищает от обрыва сети/процесса во время повторной авторизации, но не восстанавливает сессии, отозванные сервером, и не отменяет намеренную очистку данных.

В 1.7.4 исправлена подтверждённая причина сообщения «Настройки входа изменились» при сохранённых cookie/профиле: обновление cookie параллельным запросом больше не отвергает успешный ответ каталога/действия того же аккаунта. Устаревшая cookie при этом не записывается обратно; после выхода или смены аккаунта/сервера прежние ответы всё ещё отбрасываются. Сохранённые сведения пользователя не означают обход проверки доступа сервером.

## Проверки

Для изолированной экранной проверки есть вариант `gradle :app:assembleQa --offline`: пакет `com.cyberaudio.hub.qa`, подпись на телефоне «CyberAudio Hub QA». Он не использует настройки и книги основного приложения. Перед первым входом задайте в его шестерёнке `http://127.0.0.1:2078`, запустите `tools/preview.py` и `adb reverse tcp:2078 tcp:2078`. QA-APK не публикуется скриптом `build_apk.py`.

Регрессия кнопки «Назад»: в QA-копии откройте «Слушать скачанное» до входа → шестерёнка → «Войти / сменить аккаунт» → вход тестовым аккаунтом. После успеха в задаче должен остаться один экран `ShelfActivity`, а системная «Назад» из корня должна закрыть/свернуть приложение, не открывая гостевые экраны. Повторите при смене аккаунта и после регистрации. «Назад» внутри папки по-прежнему поднимает по каталогу. Не используйте рабочий сервер и личный аккаунт для этой проверки.

`build_apk.py` запускает тесты контейнера, синхронизации текста, адресов и сессий, включая HTTP-проверки на временном loopback-сервере. Для проверки на телефоне используйте `adb install -r`, не `uninstall`. Изолированный локальный сервер для UI-проверок: `python tools/preview.py` из корня проекта; он слушает только `127.0.0.1:2078` и хранит тестовую базу внутри игнорируемого каталога сборки. Основной `app.py`, порт 2077 и рабочая база не затрагиваются.

Для Android-проверок API входа/профиля и переработанного читателя предусмотрен отдельный тестовый APK: `gradle :app:assembleDebugAndroidTest`. После разрешения установки тестового пакета на телефоне выполните `adb reverse tcp:2078 tcp:2078`, установите `app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk` и запустите `adb shell am instrument -w com.cyberaudio.hub.test/com.cyberaudio.hub.LocalChecks`. Проверка подключается только к локальному preview, использует настройки тестового пакета и не разблокирует экран. Она не заменяет ручную визуальную проверку полноэкранного режима.
