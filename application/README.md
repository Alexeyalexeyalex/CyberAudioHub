# Приложение CyberAudio Hub для Android

Полка с книгами, иерархия папок как на сайте, вход в тот же аккаунт,
прослушивание и скачивание книг на телефон.

## Сразу о главном

**Этот код никогда не запускался.** Он писался в среде, где нет Android SDK
и нет доступа в сеть, поэтому собрать APK и проверить хоть один экран было
нечем. Считайте его подробным черновиком, а не готовым приложением: при
первой сборке почти наверняка понадобятся правки. Все места, где я не был
уверен, помечены в коде.

## Сборка

Нужна Linux-машина (в Windows — WSL2 с Ubuntu), Python 3.9+, Java 17.

```bash
sudo apt install git zip unzip openjdk-17-jdk python3-pip \
     autoconf libtool pkg-config zlib1g-dev libncurses-dev \
     cmake libffi-dev libssl-dev

cd application
python3 build_apk.py
```

Первая сборка качает Android SDK и NDK: это десятки минут и несколько
гигабайт. Готовый `CyberAudioHub.apk` появится в этой же папке — оттуда его
отдаёт сайт по кнопке «Скачать приложение на Android» в окне профиля.

Если сборка упала, `python3 build_apk.py --clean` начинает начисто.

## Что внутри

| Файл | Назначение |
|---|---|
| `main.py` | Экраны: вход, полка, плеер. Оформление под сайт |
| `backend.py` | Запросы к серверу, скачивание, контейнер `.cah` |
| `buildozer.spec` | Настройки сборки: разрешения, версии Android |
| `build_apk.py` | Проверяет окружение и запускает Buildozer |

## Как работает офлайн

Скачанная книга не лежит на телефоне обычными mp3. Каждая глава
упаковывается в контейнер `.cah`: своя метка формата, сведения о главе и
содержимое, перемешанное потоком байтов от ключа. Обычный плеер такой файл
не открывает — он не опознаёт формат.

**Честная оговорка про защиту.** Это преграда от случайного открытия, а не
от специалиста: ключ лежит внутри приложения, и тот, кто захочет, достанет
исходный звук. Настоящая защита требует выдачи ключей с сервера и DRM —
здесь этого нет и в таком виде быть не может.

## Про виджеты

В шторке и на экране блокировки приложение показывает уведомление с
названием книги и главы (`showNotification` в `main.py`).

Полноценного **виджета на рабочем столе** здесь нет, и на этом стеке его не
сделать: Android требует для виджетов класс `AppWidgetProvider` на Java или
Kotlin, а Kivy собирает приложение целиком из Python. Чтобы виджет появился,
в проект нужно добавлять нативный модуль и правку манифеста — это отдельная
работа, выходящая за рамки того, что можно собрать Buildozer'ом «как есть».

Текстовый режим, достижения, друзья и личные папки остались на сайте: в
